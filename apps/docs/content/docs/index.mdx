---
title: Arcton
description: A TypeScript backend framework structured for real applications, with priority-based routing, typed context and a runtime-decoupled core.
---

Arcton is a backend framework for TypeScript. You write handlers that return
values, compose behavior with middleware, and organize an application into
modules that merge into a single route tree.

```ts
import { Arcton } from '@arcton/core'

const app = Arcton()

app.get('/', () => ({ message: 'Welcome to Arcton' }))

app.get('/users/:id', ctx => ({ id: ctx.params.id }))

app.listen({ port: 3000 })
```

`ctx.params.id` is typed as `string` because the route literal says so — no
generic argument, no cast. The returned object becomes a JSON response.
