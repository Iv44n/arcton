---
title: Arcton
description: Un framework backend para TypeScript estructurado para aplicaciones reales, con enrutamiento basado en prioridad, contexto tipado y un núcleo desacoplado del runtime.
---

Arcton es un framework backend para TypeScript. Escribes handlers que
retornan valores, compones comportamiento con middleware, y organizas una
aplicación en módulos que se fusionan en un único árbol de rutas.

```ts
import { Arcton } from '@arcton/core'

const app = Arcton()

app.get('/', () => ({ message: 'Welcome to Arcton' }))

app.get('/users/:id', ctx => ({ id: ctx.params.id }))

app.listen({ port: 3000 })
```

`ctx.params.id` está tipado como `string` porque el literal de la ruta lo
dice — sin argumento genérico, sin cast. El objeto retornado se convierte en
una respuesta JSON.
